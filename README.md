# LibreTV · Cloudflare Workers 单文件版

一个**自包含的 `worker.js`**：无需安装任何东西、无需构建、无需上传静态资源。
复制 `worker.js` 里的全部代码，粘贴到 Cloudflare Worker 在线编辑器即可运行。

> English guide: [README.en.md](README.en.md)

> **⚠️ 文件较大（8.66 MB），GitHub 无法在线预览代码（会提示 “we can't show files that are this big”），这是正常的。**
> 获取代码用下面任一方式：
> - **方式一（最简单）**：打开 `worker.js` 页面 → 点右上角 **下载（⬇）图标** 保存文件 → 用记事本/编辑器打开它 → `Ctrl+A`、`Ctrl+C` 全选复制。
> - **方式二（Raw）**：点 **Raw** 按钮 → 浏览器打开原始代码 → `Ctrl+A`、`Ctrl+C`（或右键“另存为”）。

## 体积

- `worker.js` 原始约 8.66 MB，**gzip 约 2.24 MB**
- 低于 Cloudflare **免费计划 Worker 的 3 MB（gzip）上限**，免费账号即可部署
- 已把 61 个静态资源（JS/CSS/图标等）内联进 worker，因此不依赖任何外部文件

## 部署步骤（约 1 分钟，全程网页操作）

1. 登录 Cloudflare 控制台 → **Workers 和 Pages** → **创建** → **创建 Worker**
2. 给它起个名字（如 `libretv`）→ 点 **部署**
3. 部署后点 **编辑代码（Edit code）**
4. 全选删除编辑器里的默认代码，把本仓库 **`worker.js` 的全部内容粘贴进去**
   （GitHub 无法预览该大文件，获取方式见上面“⚠️”说明：用下载图标或 Raw 复制）
5. 点右上角 **部署（Deploy）**
6. 打开分配的 `xxx.workers.dev` 地址，即可看到 LibreTV 搜索页

> 想绑定自己的域名：Workers → 该 Worker → **设置 → 域和路由 → 添加 → 自定义域**，选你账号里的域名即可。

## 首页推荐（榜单）

首页榜单通过环境变量 `LZ_API_BASE` 配置，需填写一个**苹果 CMS（maccms）采集站的根地址**（**不带末尾斜杠**），例如：

```
http://example.com:5566
```

配置并保存后，首页显示 6 个榜单标签，均从该采集站实时拉取（变量即时生效，无需重新部署代码）：

| 标签 | 内容 |
|---|---|
| 最新更新 | 全站最近 24 小时更新 |
| 动作电影 | 动作片分类 |
| 国产剧 | 国产剧分类 |
| 欧美剧 | 欧美剧分类 |
| 国产动漫 | 国产动漫分类 |
| 大陆综艺 | 大陆综艺分类 |

- 榜单数据有 1 小时缓存；若显示加载失败，可能是采集站限流，稍后会自动恢复。
- 点击榜单卡片会按片名搜索，建议同时把该站配置为点播源（见下方 `DEFAULT_SOURCES`），否则点卡片可能搜不到结果。
- 榜单对应的分类 ID 已内置在代码中；若更换的采集站分类 ID 不同，需要调整代码里的分类配置。
- 不设置 `LZ_API_BASE` 时，首页不显示推荐区域，不影响搜索功能。

## 可选：环境变量（在“设置 → 变量和密钥”里添加）

| 变量 | 类型 | 说明 |
|---|---|---|
| `PASSWORD` | **密钥(Secret)** | 访问密码；不设置则站点无需密码即可访问 |
| `DEFAULT_SOURCES` | **文本(Text)** | 预置点播源，配置后新访客打开即自动加载、无需手动添加 |
| `LZ_API_BASE` | 文本 | 首页推荐采集站（苹果 CMS 采集站根地址），配置后首页显示该站榜单；不设置则不显示推荐 |
| `REQUEST_TIMEOUT` | 文本 | 上游请求超时(ms)，默认 8000 |

`DEFAULT_SOURCES` 为 JSON 数组，**下面只是格式示例，地址为占位、无法直接使用**：

```json
[
  {"name":"示例源","url":"https://demo.example.com/api.php/provide/vod","isAdult":false}
]
```
